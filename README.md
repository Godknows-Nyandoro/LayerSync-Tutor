# Sync Academy Tutor

An AI learning companion for IGCSE Computer Science 0478 that teaches, not tells.

Built with Next.js (App Router), TypeScript, Tailwind, Prisma and Neon Postgres.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env` and fill in the values
3. `npm run dev` and open http://localhost:3000
